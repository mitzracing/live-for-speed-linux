› Get started with Live for Speed Linux

one informed setup

0.4.0 public test: downloads are available for testing. Graphical package installation and real updated-game acceptance checks remain open. No software-store listing is available. Tested scope and remaining checks.

1

Choose your Linux distribution

Debian 13 or Ubuntu 24.04 · x86_64

Download the small launcher package, open it with a graphical package installer, then open Live for Speed Linux from your application menu. The package does not contain the game.

Download .deb · 0.4.0 public test

Release notes and checksums

Arch Linux or Manjaro · x86_64

An Arch test package is available on GitHub. The AUR/Pamac route is not published or verified yet; this download is not a software-store listing.

Download Arch package · public test
Another distribution or advanced installation

See the source and compatibility instructions. This release requires Linux x86_64 and a Vulkan-capable graphics driver.

2

Open Live for Speed Linux

Find the game in your application menu. Choose Install and play after reviewing the download size and public-test notice. Setup shows progress and can resume interrupted downloads.

3

Play now. Click the same icon next time.

LFS opens when setup finishes. Your settings, setups, replays, and downloaded skins stay yours. The launcher can repair compatibility components without replacing your game.

Public-test channel: first installation starts with LFS 0.8C20 new graphics. LFS manages its own game updates. v0.1.6 remains the old-graphics 0.7G fallback.
