› Get started with Live for Speed Linux

one informed setup
1

Install the verified source release

git clone --branch v0.3.0 --depth 1 https://github.com/mitzracing/live-for-speed-linux.git
cd live-for-speed-linux
make test && sudo make install

The AUR recipe is ready, but publication still awaits maintainer SSH access.

2

Open Live for Speed Linux

Read the source, size, path, and legal notice. Confirm the download once.

3

Launch the game directly

The wrapper verifies the complete stock inventory before Wine starts the untouched game.

Public-test channel: v0.3.0 bootstraps exact LFS 0.8C20 new graphics and records later versioned in-game updates after LFS exits. Immutable v0.1.6 remains the old-graphics 0.7G fallback. AUR publication is pending maintainer SSH access.

What it verifies

            
    
              
  • Official LFS installer size and SHA-256
    • 
              
  • Every packaged or locally recorded protected game file
    • 
              
  • Every required Wine runtime file and link
    • 
              
  • Private DXVK D3D11 and DXGI DLL copies
    • 
            

          

          

            
What it preserves

            
    
              
  • Settings and controller profiles
    • 
              
  • Unlock state and player profiles
    • 
              
  • Setups, layouts, replays, and screenshots
    • 
              
  • Existing shader cache between launches
    • 
            

          

          
No game binaries, official logos, unlock tools, or modified assets are distributed by this project.
